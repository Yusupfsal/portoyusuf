# Portfolio Web - Mohamad Yusup Faisal

Website portofolio modern, responsif, dan elegan yang dibangun menggunakan **Semantic HTML5**, **Modern Vanilla CSS**, dan **Modular Vanilla JavaScript** (Dark Mode, Glassmorphism, & Micro-animations).

---

## 🚀 Fitur Unggulan
- **Desain Modern & Elegan**: Mengusung tema dark mode futuristik dengan aksen Electric Cyan, glassmorphism blur, dan ambient glowing light.
- **Micro-Interactions**:
  - Efek dynamic typing pada hero section.
  - Animasi progress bar keterampilan yang terisi otomatis saat discroll ke layar (*IntersectionObserver*).
  - Efek interaktif 3D tilt pada kartu proyek (*Hover Project Card*).
  - Foto profil dengan multi-layer glowing animated rings.
  - Navbar frosted glass otomatis saat discroll dengan active link spy.
- **Navigasi Responsif**: Drawer menu mobile dengan transisi halus dan hamburger toggle.
- **Modal Preview & Cetak CV**: Fitur pratinjau Curriculum Vitae yang siap dicetak langsung menjadi file PDF.
- **Form Kontak Interaktif**: Dilengkapi validasi form real-time dan notifikasi feedback.
- **Tanpa Framework Berat**: 100% murni HTML, CSS, dan JS, sangat ringan, cepat, dan terstruktur.
